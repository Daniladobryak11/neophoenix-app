# Нео Феникс — приложение для сотрудников (iPhone)

Нативное приложение на SwiftUI для CRM магазина «Нео Феникс» (neophoenix.ru).
Работает с тем же сервером и базой, что и CRM на сайте: изменения видны сразу и там, и там.

## Что уже есть (версия 0.1)
- Вход по email и паролю сотрудника, ключ хранится в связке ключей iPhone; вход по Face ID.
- Заказы: счётчики, фильтры, поиск, карточка заказа, «Взять в работу», смена статуса, звонок и WhatsApp.
- Заявки: новые / в работе / закрытые, «Взять», «Обработана», звонок.
- Тема: автоматически, светлая или тёмная.

## Дальше
Задачи, чаты, смена с напоминанием по геолокации, push-уведомления Apple, Live Activities («чёлка» iPhone).

## Сборка
GitHub Actions собирает приложение в облаке (macOS) при каждом пуше в `main` или `app-v1`:
вкладка Actions → последний запуск → Artifacts → `NeoPhoenix-unsigned-ipa`.
Проект Xcode генерируется из `project.yml` (XcodeGen). Подпись и TestFlight подключим после
оформления аккаунта разработчика Apple.

## Сервер
Нужна версия сайта 6.23+ (`/api/app.php` — вход для приложения по ключу `X-App-Token`).
